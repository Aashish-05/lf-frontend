# Lost & Found Item Management System – Frontend

A web-based **Lost & Found Item Management System** developed using the **MERN Stack**.  
This application helps college students report, search, and manage lost or found belongings efficiently.

---

## 🚀 Live Deployment

🔗 Frontend Live URL:  
https://lost-and-found-five-indol.vercel.app/

---

## 📌 Features

### Authentication
- User Registration
- User Login
- Secure JWT Authentication
- Logout Functionality

### Lost & Found Management
- Add Lost/Found Items
- View All Reported Items
- Search Items by Name
- Update Item Details
- Delete Item Entries

### Security
- Password Hashing using bcrypt
- JWT-based Authorization
- Protected Dashboard Routes

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Axios
- React Router DOM
- CSS / Bootstrap

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt
